# 素记 Plainote

本地 Markdown 工作笔记桌面应用。采用 Electron、React、TypeScript 和 CodeMirror 6，沿用温润素雅、文稿居中的已确认设计。

当前为第一阶段开发版本：可以打开本地文件夹、读取和编辑真实 `.md` 文件，不需要导入或账号。

## 运行

需要 Node.js 22.12+ 与 npm。首次安装需要联网下载 Electron。

```sh
npm ci
npm run dev
```

运行构建后的版本：

```sh
npm run build
npm start
```

点击「打开笔记文件夹」，选择已有 Markdown 目录。下次启动会重新打开最近使用的目录。原型仍可在 `prototype/index.html` 独立查看。

## 已实现

- Markdown 目录、多标签、名称与路径筛选、快速打开、新建笔记。
- 即时预览：标题、强调、行内代码、待办勾选、代码块与语言高亮、多行引用、列表、分隔线、普通链接文本、GFM 表格；支持源码模式、撤销重做、大纲跳转。
- 自动保存，保存前写恢复副本，保存失败保留编辑内容。
- 外部修改检查、版本冲突比较和另存副本；冲突不会自动覆盖磁盘版本。
- 重启后恢复未保存内容；原笔记已删除时可恢复为新文件。
- 原文中的 BOM、未编辑部分的换行、YAML 和未知 Markdown 语法保留。
- 浅色与深色主题、正文字号设置、侧栏收起、系统窗口操作。

Mac 使用 ⌘，Windows 使用 Ctrl：O 打开笔记库、P 快速打开、N 新建、S 保存、逗号打开设置。编辑器内的查找针对当前文稿。

## 当前范围

图片嵌入、Obsidian 双链导航、反向链接、全文搜索和文件重命名安排在后续阶段。现有图片与双链语法会保留在原文件中。数学公式、Mermaid 和 HTML 渲染尚未实现。代码块支持反引号、波浪线及缩进形式；编辑代码块时显示围栏。点击表格或将光标移入表格后，整表显示源码以直接编辑。普通链接目前呈现文本，点击用于编辑。单篇文件上限 20 MB，隐藏目录与符号链接不作为笔记扫描。

恢复副本存放在 Electron 的用户数据目录 `recovery/` 中，按笔记库隔离。正常保存后清理对应副本；强制终止之前尚未进入恢复备份的输入仍可能丢失。遇到错误请处理提示或保留副本再退出。

macOS 已执行真实桌面验证。Windows 已提供构建配置，尚未在 Windows 环境验证。当前版本没有签名、自动更新或同步。

## 验证与打包

```sh
npm test
npm run build
npm run test:desktop
npm run test:markdown
npm run package
```

桌面测试需要图形桌面环境，使用临时笔记库和独立应用数据目录，覆盖真实编辑落盘、冲突、取消退出和异常退出恢复；不会写入项目中的 `testdata/`。测试前应先执行构建。`npm run package` 生成本机平台应用目录，`npm run dist` 生成安装包；发布签名需另行配置。

## 项目文件

- `src/electron/`：本地文件服务、有限 IPC、窗口与菜单。
- `src/renderer/`：桌面界面和 CodeMirror 编辑器。
- `src/shared/`：保存会话、恢复与原文编辑逻辑。
- `tests/`：文件服务、编辑保存与桌面集成验证。
- `PRODUCT.md`、`DESIGN.md`、`docs/plans/`：产品决策、设计规范与阶段计划。
