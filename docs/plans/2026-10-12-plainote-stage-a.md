# 第一阶段实施计划

状态：用户已授权继续开发；技术栈 Electron + React + TypeScript + CodeMirror 6，沿用已认可界面。只交付第一阶段可运行版本，不把全文搜索、插件、同步或复杂双向链接纳入本轮。

1. 创建构建、开发与打包脚本，保持原型独立可查看。
2. 先测试文件服务：Markdown 扫描、Unicode 路径、原文读取、版本校验、原子替换、串行保存、库边界与符号链接保护、恢复副本。
3. Electron 主进程选择本地文件夹，提供有限 IPC；渲染器隔离，不直接获取 Node.js 或任意文件访问。
4. React 接入真实目录、多标签和 CodeMirror；实现基础即时预览、源码切换、编辑撤销、输入法友好行为、大纲、主题。
5. 自动保存记录真实状态，保存前记录恢复内容；外部版本冲突不自动覆盖；关闭前完成保存或明确保留恢复内容。
6. 用临时库运行桌面集成验证，实际读取和编辑文件；原有 testdata 只用于可选读取性能验证，不写入。
7. 独立代码审查，修复关键问题，输出运行说明与当前限制。

验收：npm test、npm run build 通过；macOS Electron 能打开笔记库、编辑、保存、重新打开，中文路径/BOM/CRLF 保留测试通过，冲突不会覆盖磁盘版本。Windows 提供构建配置，但需要 Windows 环境另行验证，不宣称已经验证。
