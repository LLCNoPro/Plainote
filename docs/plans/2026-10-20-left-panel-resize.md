# 左侧面板宽度调整

用户要求左侧面板增加与右侧一致的宽度调整。沿用现有界面与分隔线，不改变笔记和目录操作。

左右两侧共用拖拽逻辑：目录面板右边界向右拖增宽，侧栏左边界向左拖增宽，9px 命中区域与 1px 分隔线保持原视觉，悬停/拖拽/聚焦使用已有强调色。两侧分别记录 localStorage，折叠展开及重启恢复宽度，硬限制为 220–560px；窗口较窄时额外限制两侧总宽，为正文及工具栏保留 360px。

分隔条提供 separator 语义和宽度读数，支持左右方向键、Home/End 调整。鼠标松开、窗口失焦或组件卸载时清理监听并恢复原光标/文字选择状态。

验证：先补失败的真实 Electron 交互用例，再实现。99 项单元测试与正式构建通过，临时笔记库中 8 个场景通过：两侧独立拖拽、深浅主题、限制与键盘、折叠恢复、松手与失焦、重启恢复、900px 窄窗口与正文空间、原文不变。截图及报告位于 `.impeccable/review/panel-resize/`；运行 `npm run test:panels` 可重现。

独立代码/视觉复核确认沿用原设计，未新增字体、配色或圆角；设计文档复核保留 DESIGN.md 与 sidecar，未顺带修复原有右侧默认宽度记录差异。本任务与尚未提交的长文档大纲修复共存，未覆盖其改动。未打包或发布，Windows 未实机验证。
