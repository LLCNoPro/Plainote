# 素记界面设计草案

状态：用户已确认“文稿居中”布局、温润素雅气质，并认可高保真原型的界面效果；该原型作为后续开发的视觉基准，见 prototype/index.html。  
设计方法：Impeccable 的 shape / Operate；下文保留设计依据与候选取舍。原型交付与验证边界见 2026-10-12-plainote-prototype-review.md。

## 使用目标

工作记录者在会议或项目推进时，能快速找到当前项目并开始输入。界面必须让正文、当前文件位置和保存状态一眼可见；信息管理围绕原有文件夹展开。

## 主窗口方案

推荐“文稿居中”：左侧保留紧凑目录，中间使用舒适的正文宽度，右侧提供轻量辅助信息。功能通过工具条、键盘与上下文菜单逐步展开。

### 布局候选及取舍

| 候选 | 结构 | 适用与成本 |
| --- | --- | --- |
| 文稿居中，推荐草案 | 紧凑目录、持续可见的标签页、中央文稿、可收起的辅助栏 | 写作与资料管理平衡；窗口变窄时要收起右栏 |
| 项目资料并列 | 左侧项目目录、第二列笔记列表、中央正文、按需打开辅助栏 | 适合频繁浏览项目文档；多一列会减少写作空间 |
| 专注正文 | 正文为主，目录和关联信息临时展开，快捷键承担更多导航 | 适合长文写作；新用户对全库结构的感知较弱 |

三种方案均遵守已确认的暖白、墨色、少量青绿色。它们是布局候选，不代表用户已经选定。

## 配色与排版建议

- 主编辑区使用偏暖的浅底色；侧栏比正文略深，主要靠底色差与细分隔线区分区域。
- 正文使用墨色，次要文字也要保证可读性；青绿色集中用于链接、当前选中项、键盘焦点和关键操作。
- 错误、警告与成功使用独立语义颜色，并配合图标和文字，不能仅靠颜色表示状态。
- 界面文字优先使用平台中文无衬线字体；正文默认清晰易读，后续允许用户选择字体。
- 建议界面字号 13–14，正文 16，正文行高约 1.7；这些是待原型验证的起点，尊重系统缩放。
- 正文限制阅读宽度，不让宽窗口中的每行文字无限延伸；中文每行长度需要单独观察。
- 文件行适度紧凑，正文段落更舒展。圆角、阴影与动效仅服务控件和状态识别。
- 深色主题使用带暖色倾向的深背景与较浅墨色层级，重新验证对比度，不机械反转浅色主题。

## 主要交互

### 编辑与标签页

当前标签明显区别于非当前标签，长标题截断后可查看完整名称。未保存使用明确状态标识。点击链接进入目标笔记；编辑链接文字时保留源码。即时预览只改变呈现，光标进入相关区域时显示对应标记。

顶部以路径和更多菜单为主，不用密集格式工具条占据正文空间。常见格式可通过快捷键、菜单或选中文字后的操作访问。

### 搜索与快速打开

全文搜索显示在左侧，用标题、路径与正文片段呈现结果；正文中同步定位匹配位置。快速打开使用居中的键盘弹窗，输入标题，方向键选择，回车打开，Escape 关闭并返回原焦点。两者使用不同名称与快捷键提示。

### 新建与模板

新建默认在当前目录生成笔记并立即聚焦标题或正文。模板选择器列出空白、会议记录、项目文档与工作日志，不要求用户先处理模板配置。重名时提供可编辑的新名称。

### 图片与附件

粘贴或拖入图片后显示插入状态，失败时给出原因与重试入口。可以查看完整图片与打开附件所在位置。现有附件缺失时保留引用并显示“找不到附件”，不自动移除 Markdown。

### 大纲与反向链接

右侧通过标签切换两类信息，避免重复占用空间。大纲跟随当前位置，点击跳转；反向链接显示来源笔记和引用片段。没有反向链接时解释用途，并提供插入链接的操作提示。

## 必须设计的状态

| 状态 | 界面处理 |
| --- | --- |
| 首次打开 | 展示“打开笔记文件夹”和“新建笔记库”，不要求注册 |
| 空目录 | 保留目录位置，提供新建笔记与模板入口 |
| 索引中 | 目录和已打开正文先可用；搜索提示仍在建立索引 |
| 无搜索结果 | 展示当前搜索条件，允许清除或修改范围 |
| 保存失败 | 持续显示失败提示，提供重试与另存为，保留正文 |
| 外部修改冲突 | 明确“磁盘内容”和“当前编辑内容”，可以比较、保留副本或选择版本 |
| 图片缺失 | 原位置提供说明与路径查看，保留引用 |
| 链接歧义 | 展示候选文件完整路径，用户明确选择 |
| 笔记被外部删除 | 保留当前内容，允许另存为或关闭 |

## 尺寸与可访问性

桌面主要检查 1440×900、1280×800 与 1024×768，并检查系统缩放。初始建议左栏约 230、右栏约 240，可拖动调整；正文阅读宽度约 680–760，原型阶段实测。

窗口变窄时先收起右栏，再允许收起目录。面板再次打开时恢复宽度和滚动位置。使用标准键盘焦点、可识别的控件名称、足够对比度与一致图标。图标按钮提供工具提示，重要操作不能只在悬停时出现。

## 后续交付

本轮交付布局与交互草案。选定布局后制作高保真、可浏览的桌面界面原型，包含浅色和深色主窗口、全文搜索、快速打开、首次使用、设置、保存失败与冲突状态。原型应明确标注示例数据；真实 Markdown 编辑和文件读写在应用实现阶段验证。

界面验收看真实任务：用户能找到笔记、开始记录、辨认所在目录与保存状态，并在错误时知道怎样保留内容。
