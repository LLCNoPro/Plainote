# AI 对话框实现计划

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 为素记增加右侧 AI 对话侧边栏，可检索笔记、总结、写作辅助，对接 DeepSeek（Anthropic 兼容接口）。

**Architecture:** Electron 主进程负责 DeepSeek 调用（Node fetch + SSE 流式）与全库检索，通过 IPC 流式推送给渲染层；渲染层新增右侧双 Tab（大纲 | AI 对话）聊天 UI 与设置里的 AI 配置。

**Tech Stack:** Electron、React 19、TypeScript、Node fetch（SSE 流式）、现有 IPC（ipcMain.handle / webContents.send）。

---

### Task 1: 共享类型与桥接

**Files:**
- Create: `src/shared/ai.ts`
- Modify: `src/shared/types.ts`

定义 `AiConfig`（baseUrl/apiKey/model）、`AiChatMessage`、`AiContext`、`AiSearchHit`、新增 ErrorCode `'AI_NOT_CONFIGURED' | 'AI_ERROR'`，`PlainoteBridge` 增加 ai 相关方法。

### Task 2: AI 配置存取（主进程）

**Files:**
- Create: `src/electron/ai.ts`
- Test: `tests/ai.test.ts`

`readAiConfig()` / `saveAiConfig(config)`：读写 `preferences.json` 的 `ai` 字段（默认 baseUrl `https://api.deepseek.com/anthropic`、model `deepseek-chat`）。

### Task 3: 全库关键词检索（主进程）

**Files:** `src/electron/ai.ts`，Test: `tests/ai.test.ts`

`searchNotes(query, files, readNote)`：把 query 与每篇笔记做关键词重叠打分，返回 Top-N `{ path, name, snippet }`。纯函数、可单测。

### Task 4: DeepSeek 流式调用（主进程）

**Files:** `src/electron/ai.ts`，Test: `tests/ai.test.ts`（mock fetch）

`streamChat(config, messages, context, onDelta, signal)`：组装 system 提示 + 上下文 + 历史，POST `{baseUrl}/v1/messages`，SSE 解析 `content_block_delta` 增量文本回调 `onDelta`，`message_stop` 结束。支持 AbortSignal 中断。

### Task 5: IPC 与 preload

**Files:** Modify `src/electron/main.ts`、`src/electron/preload.cjs`

注册 `ai-get-config` / `ai-set-config` / `ai-search` / `ai-chat`（返回 sessionId）/ `ai-cancel`；主进程用 `webContents.send` 发 `ai-token` / `ai-done` / `ai-error`。preload 暴露对应方法与 `onAiToken/onAiDone/onAiError` 订阅。

### Task 6: 设置 AI 区块（前端）

**Files:** Modify `src/renderer/App.tsx`、`styles.css`

设置弹窗新增「AI」区块：API 地址 / API Key / 模型 三个输入，读写 `aiGetConfig`/`aiSetConfig`。

### Task 7: 右侧面板双 Tab

**Files:** Modify `src/renderer/App.tsx`、`styles.css`

右侧 `inspector` 增加 Tab 切换（大纲 | AI 对话），AI Tab 渲染 `<AiPanel>`。

### Task 8: 聊天 UI

**Files:** Create `src/renderer/AiPanel.tsx`，Modify `styles.css`

消息列表（流式）、上下文标签、输入框、发送、快捷指令（总结/续写/润色/翻译）、「检索全库」、「插入到笔记」。

### Task 9: 测试与回归

**Files:** Test `tests/ai.test.ts`、`tests/ai-desktop.cjs`

单测覆盖检索打分 + SSE 解析；桌面集成覆盖 聊天/检索/上下文/插入/配置 落盘；跑通全量回归（npm test + 桌面测试）。
