# 图片附件与文件管理设计方案

日期：2026-10-17。

状态：已按用户要求记录方案，待实现。本文不代表下列功能已经完成或通过验收。

## 目标与范围

优先补齐两组功能：

1. 图片预览、截图粘贴、拖入图片、附件位置设置、打开附件。
2. 笔记及目录跨目录移动、删除目录、重命名或移动时维护引用。

沿用 Electron、React、TypeScript 和 CodeMirror 6，以及现有温润素雅界面。正文和附件继续直接存放在本地笔记库，不引入独立内容数据库。

本轮不实现独立全文搜索界面或模板系统；AI 查询能力的后续完善另行安排。

## 图片与附件

### 图片预览与打开

- 即时预览和阅读模式支持普通 Markdown 图片 `![说明](相对路径)` 与 Obsidian 图片嵌入 `![[图片.png]]`。
- 图片随正文宽度缩放，保持原始比例；点击可放大查看。
- 源码模式保留可编辑的图片语法；即时预览延续光标附近显露源码的现有交互。
- 图片不存在、路径无法确定或读取失败时显示可理解的占位与原因，原引用保留。
- 点击本地附件链接，通过系统默认应用打开相应文件。

### 截图粘贴与拖入

- 在可编辑正文中粘贴截图或拖入图片，将图片保存到配置的附件目录，再在插入位置写入标准 Markdown 相对路径引用。
- 自动创建所需附件目录；遇到同名附件自动生成不冲突的名称，不覆盖已有文件。
- 附件保存成功后才插入引用；失败时说明原因，保留当前笔记内容。
- 阅读模式和文件操作锁定期间禁止导入图片，保持现有只读约定。
- 异步导入完成后仍需核对目标笔记和笔记库，避免切换笔记或笔记库后插入到错误文档。

### 附件位置设置

提供两种方式：

| 方式 | 行为 | 适用场景 |
| --- | --- | --- |
| 笔记库统一目录（默认） | 默认写入库根目录下的 `attachments/`，允许修改库内相对目录 | 集中管理附件 |
| 当前笔记旁的目录 | 将所设相对目录解析到当前笔记所在目录 | 连同项目目录一起迁移 |

配置按笔记库保存。变更只影响新附件，不自动搬迁原有附件。生成引用时相对于笔记位置计算路径，支持中文、空格等文件名。

## 文件管理

### 跨目录移动

- 文件和目录增加“移动到…”入口，使用目录选择器选择笔记库内的目标目录，支持移动到库根目录。
- 不允许目录移动到自身或其子目录；遇到目标重名则提示并停止，不覆盖现有内容。
- 移动前保存受影响的编辑内容，操作期间锁定相关编辑与文件操作。
- 成功后更新文件树、已打开标签、当前笔记路径及恢复记录；切换库或关闭窗口需等待操作完成。

### 删除目录

- 删除确认显示目录路径及包含的笔记、附件数量，明确整个目录及其内容将移入系统回收站。
- 先保存目录内已打开笔记的编辑；存在保存失败或版本冲突时停止。
- 回收站操作失败时保留目录和标签，不退化为永久删除。
- 成功后清理对应文件树和打开标签；需要的未保存恢复内容继续按现有规则保留。
- 其他笔记中指向被删除内容的引用保持原样，便于从回收站恢复后继续使用。

### 重命名与移动更新引用

维护以下引用形式：

- 普通 Markdown 笔记链接和图片引用。
- Obsidian 双链及嵌入，如 `[[目录/笔记]]`、`[[笔记|显示名称]]`、`![[图片.png]]`。
- 保留引用的显示名称、标题锚点和块定位后缀，仅修改需要变化的目标路径。

更新同时考虑两个方向：其他笔记指向被移动或重命名目标的引用，以及被移动笔记自身指向其他笔记或附件的相对路径。目录操作需将整个子树的路径变化纳入分析；随目录一起移动的附件也需正确解析。

只更新能明确解析到实际目标的引用。对于同名歧义或原本无法解析的引用，保留原文并报告具体位置，不猜测目标。代码块和行内代码中的示例文本不作为引用修改。

该功能维护引用路径，不等同于完整实现双链补全、反向链接面板或标题/块跳转。

## 架构与可靠性

- 渲染层负责设置、导入入口、图片展示和文件操作交互；CodeMirror 扩展负责预览及粘贴/拖入行为。
- 主进程通过有限 IPC 负责附件读写与打开、目录操作、引用分析及批量修改；文件访问保持在当前笔记库边界内。
- 图片读取使用受控资源接口，不向笔记内容开放任意文件读取或脚本执行能力。
- 重命名与移动先生成受影响文件和引用变更计划，保存编辑并核对磁盘版本后再执行。
- 批量修改前记录原内容、路径变化和操作进度，形成可恢复日志；失败时尝试恢复，并明确报告仍需恢复的项目，不显示虚假的成功。
- 引用修改沿用原文保留约定，保留 BOM、未修改区域的换行、YAML 和未知语法。
- 已打开的被引用笔记同步刷新内容与保存版本，避免旧编辑会话将更新后的引用覆盖回去。

## 验证与验收

先编写关键行为的失败测试，再实现文件服务、引用处理、IPC 与界面。单元测试覆盖真实临时文件，桌面测试使用独立临时笔记库与应用数据目录。

必须验证：

- 两种图片语法的预览、放大和缺失图片状态。
- 截图粘贴、图片拖入、重名避让、两种附件位置及配置持久化。
- 导入失败和导入期间切换笔记不会插入错误引用；阅读模式不导入。
- 附件通过系统打开；中文、空格及特殊字符路径正确解析。
- 文件和目录跨目录移动；重名、自身/子目录移动等无效操作被拒绝。
- 重命名/移动后，外部引用和笔记自身相对引用正确；显示名、锚点及块后缀保留。
- 歧义引用、代码示例和未知语法不被误改。
- 目录删除确认、取消、系统回收站失败、保存冲突及已打开标签同步。
- 批量引用更新失败可恢复，外部修改不被静默覆盖。
