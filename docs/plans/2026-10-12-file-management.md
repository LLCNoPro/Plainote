# 目录创建与笔记删除

用户明确要求补齐创建目录和删除笔记。沿用已批准的目录与多标签界面。

目录：新增独立目录扫描，让空目录也可见；新建入口可输入相对路径，安全逐级创建嵌套目录；点击目录后，新笔记/子目录默认创建于该目录。禁止路径越界、隐藏目录和符号链接，重名给出提示。

删除：每条笔记与正文工具栏提供删除入口，展示文件路径并确认；先保存已打开笔记的最新编辑，再按版本校验调用系统回收站。保存、版本冲突或回收站操作失败时保留文件与标签。成功后移除相应标签/恢复记录，刷新目录。切库/关闭等待操作，拒绝导入删除期间迟到的读取结果。

先补文件服务失败测试，再实现有限 IPC、目录/删除界面和临时库桌面验证。实际回收站验证使用独立临时文件；常规自动化以临时移动函数代替系统回收站，确认调用及原文可恢复。原有 testdata 不写入。
