## 剩余功能与实现边界

| 功能 | 当前状态与缺口 |
| --- | --- |
| 全文搜索 | 已有名称/路径筛选和 AI 关键词检索；没有独立正文搜索界面、文件夹过滤与命中上下文展示 |
| 模板 | 未实现 Markdown 模板选择/管理及会议记录、项目文档、工作日志内置模板 |
| 图片与附件 | 未实现图片显示、截图粘贴、拖入、附件位置设置和通过系统应用打开其他附件；现有语法保留原文 |
| 链接交互 | 普通 Markdown 链接仅呈现文本样式；未实现目标打开、Obsidian 双链导航/补全、反向链接、标题/块定位与同名消歧 |
| 文件管理 | 新建、重命名及笔记回收站删除已有；未实现跨目录移动入口、目录删除、受影响引用更新与批量操作日志/恢复 |
| 导航 | 多标签、按名称/路径快速打开、大纲已有；未实现浏览前进/后退与常用笔记入口 |
| 最近笔记库 | 已自动重开最后一个库；未实现多个最近笔记库列表 |
| YAML 元数据 | 保留原文；未实现标签和别名的语义识别、检索与链接解析 |
| 历史版本 | 未保存恢复副本、冲突副本与系统回收站已有；未实现已保存版本的历史列表与回滚，正常保存会清理对应恢复副本 |
| 偏好 | 明暗主题、8 种主题色、字号已有；字体选择及附件保存位置未实现 |
| AI 上下文 | 当前笔记、选区、自动关键词检索与 AGENT.md 概览已有；原设计的上下文标签逐条移除、手动选择检索笔记未实现，当前交互改为自动检索 |
| AI 检索规模 | `ai-search` 与 `readAllNotes()` 都仅读取按路径排序的前 200 篇扫描结果；概览与自动检索受此限制，不能称为任意规模全库检索 |
| AI 后续能力 | 向量检索、多轮工具调用、图片附件、API Key 加密存储未实现 |

数学公式、Mermaid、HTML 渲染与自动更新目前也未实现，但不属于原第一版已承诺功能。同步、账户、插件市场、完整任务管理、移动端、图谱、Canvas/Excalidraw 编辑器仍属原规划暂不开发范围。
